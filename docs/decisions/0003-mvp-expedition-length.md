# ADR 0003: MVP Expedition Length

## Status

Proposed

## Decision

Cap the first MVP expedition at three active turns, followed by reflection and a memento.

## Rationale

Three turns demonstrate instruction, response, adaptation, and payoff while keeping the first experience short enough to test repeatedly.

## Consequences

- The first narrative arc must be compact.
- Longer adventures need a later continuation model.
- The state model should support longer journeys without requiring them initially.
