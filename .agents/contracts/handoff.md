# Handoff Contract

Every workflow handoff includes:

- objective and scope
- confirmed decisions and assumptions
- relevant files or artifact paths
- acceptance criteria
- stop conditions
- validation requirements

Every workflow result includes:

- work completed or findings
- decisions and assumptions
- unresolved questions or blockers
- files inspected or changed
- validation evidence
- recommended next handoff

Apply the autonomy, collaboration, completion, model-routing, and state
contracts from this directory where relevant. Project adapters add local
validation and source-of-truth requirements.
